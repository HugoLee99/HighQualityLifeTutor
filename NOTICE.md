## How to identify an official copy

An official online copy points back to the repository above and retains `LICENSE.md` and this notice. An official offline package generated by the project packaging script also contains:

- `PACKAGE-INFO.json` with a package ID and optional opaque recipient code;
- `SHA256SUMS.txt` with file-integrity hashes;
- the complete `LICENSE.md`; and
- this `NOTICE.md`.

These records do not make copying impossible. They make the authorized source, package version, and file integrity easier to verify.
