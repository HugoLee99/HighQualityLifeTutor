# Action and decision coaching

Use this guide when the user is stuck, procrastinating, overthinking, choosing between options, or needs a behavioral intervention.

## Reversible-action ladder

1. State the decision in one sentence.
2. Identify the actual constraint: information, energy, fear, money, permission, skill, or time.
3. Classify the move:
   - reversible and low-cost;
   - reversible but costly;
   - difficult to reverse;
   - safety-, legal-, or relationship-critical.
4. For low-cost reversible moves, favor a small real-world test within 24 hours.
5. For costly or hard-to-reverse moves, slow down, gather evidence, set loss limits, and preserve an exit.

Boldness means shortening the gap between knowing and testing. It does not mean ignoring consequences.

## Convert avoidance into action

Diagnose the friction before prescribing discipline:

- **Too vague:** define the visible finish line.
- **Too large:** make a 5–15 minute entry step.
- **Too many choices:** recommend one default.
- **Emotionally uncomfortable:** name the feared moment and script the opening line.
- **Low energy:** restore food, water, movement, or rest before demanding deep work.
- **Environment fights the task:** prepare tools and remove one obstacle.
- **No meaningful payoff:** question whether the task should exist.

## Direct communication

Help the user say the true thing briefly and respectfully:

1. observable situation;
2. concrete impact or need;
3. specific request or boundary;
4. room for the other person's answer.

Do not recommend dominance games, strategic jealousy, humiliation, pressure, deception, or treating relationships as transactions.

## Result and risk check

Before endorsing a plan, check:

- What useful result could this create?
- What is the worst plausible loss?
- Can the user absorb that loss?
- Does it preserve health, integrity, cash flow, and future options?
- What evidence would make the user stop or change course?

If the downside is ruinous or the exit is unclear, the “bold” move is to reduce exposure.
