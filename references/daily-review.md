# End-of-day review

The review should create learning and a better tomorrow, not a verdict on the user's character.

## Input handling

Accept whatever the user has: a paragraph, voice-transcript text, completed tasks, meals, screen-time notes, mood, photos, or “today was a mess.” Extract facts first. Ask a follow-up only when a missing fact materially changes the advice.

## Review sequence

### 1. Evidence ledger

Summarize what actually happened without embellishment:

- completed outputs and commitments kept;
- sleep, meals, movement, recovery, and notable symptoms if mentioned;
- important decisions or conversations;
- tasks avoided, interrupted, or abandoned;
- meaningful context outside the user's control.

### 2. Outcome check

State whether the day's must-win outcome was achieved, partially achieved, changed deliberately, or missed. If no must-win was set, infer the day's main outcome cautiously and label it as an inference.

### 3. Pattern diagnosis

Identify at most:

- one thing that worked and should be repeated;
- one friction point and its likely trigger;
- one mismatch between intention and behavior.

Do not manufacture a deep lesson from a single ordinary event.

### 4. Coach's judgment

Give a candid but proportionate assessment:

- **Keep:** behavior or system producing value;
- **Change:** one concrete adjustment;
- **Drop:** unnecessary demand, friction, or self-punishing story.

### 5. Tomorrow setup

Define:

- one must-win outcome with a visible finish line;
- one 5–15 minute first action;
- health floors appropriate to the context;
- an if-then fallback for the most likely disruption;
- any item intentionally deferred so it stops consuming attention.

## Default output

Use this compact format unless the user asks for something else:

**今天事实**

Two to six bullets grounded in the user's report.

**导师判断**

One short paragraph explaining what mattered most.

**保留 / 调整 / 放下**

- 保留：...
- 调整：...
- 放下：...

**明天**

- 必赢结果：...
- 第一动作：...
- 健康底线：...
- 如果被打断：...

## Optional lightweight ratings

Only when useful, rate 1–5 for energy, physical care, meaningful output, and emotional steadiness. Ratings describe the day, not the person. Always attach one sentence of evidence; never compute a grand “life score.”
